# Codewars & Python Practice

Organized collection of coding practice solutions and Python learning exercises.

## Structure

- `codewars/python` — Codewars kata solutions in Python (named by challenge topic)
- `codewars/javascript` — Codewars kata solutions in JavaScript
- `python-basics/` — Python fundamentals by topic (lists, strings, OOP, file handling, etc.)
- `computer-graphics/` — Turtle / graphics labs and projects

## Topics in `python-basics`

| Folder | Focus |
|--------|--------|
| introduction | Variables, printing, swapping |
| strings | Slicing, formatting, cleaning |
| lists | CRUD, comprehension, sorting |
| tuples | Tuple basics and looping |
| dictionaries | Keys, values, nesting |
| sets | Set creation and values |
| conditionals | if/elif, match/case |
| loops | for/range, while |
| functions | Args, kwargs, lambda, recursion |
| file-handling | Read/write notes and files |
| error-handling | try/except patterns |
| oop | Classes, `self`, encapsulation |
| modules | Imports and user modules |
